# Analysis *Perfect* Rocket

## Project Overview

A miniature G-class rocket with a custom nose cone, fin can, and avionics bay to house an Arduino NANO to record temperature and pressure during flight. 

* **Primary Objective:** Design, manufacture, and fly a custom built rocket with a G-class rocket to achieve an altitude of 2500 ft. 

## List of 3D Printed Parts (Modeled in SolidWorks) 

- Fin Can
- Nose Cone
- Avionics Bay

## Electronics

- Arduino NANO
- BMP 280 Sensor
- Micro SD Card + Module
- 9V Battery
